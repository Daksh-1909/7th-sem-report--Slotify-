\chapter{Literature Review \& Technology Stack}

\section{Technology Stack Matrix}

\subsection{Frontend Layer}

\begin{itemize}
\item \textbf{React} (\texttt{\^18.2.0}): Core UI library providing virtual DOM reconciliation, hooks, and context.
\item \textbf{Vite} (\texttt{\^7.3.0}): Next-generation frontend build tooling with near-instant hot module replacement (HMR).
\item \textbf{Tailwind CSS} (\texttt{\^3.4.0}): Utility-first CSS engine implementing the bespoke Neo-Bauhaus high-contrast design system.
\item \textbf{React Router DOM} (\texttt{\^7.18.2}): Declarative client-side routing, protected route wrappers, and dynamic query param parsing.
\item \textbf{Axios} (\texttt{\^1.19.0}): Promise-based HTTP client equipped with request authorization and response token-refresh interceptors.
\item \textbf{Lucide React} (\texttt{\^0.298.0}): Comprehensive, consistent vector icon library.
\item \textbf{date-fns} (\texttt{\^3.0.6}): Lightweight, immutable date arithmetic, timezone formatting, and calendar math.
\item \textbf{Lenis} (\texttt{\^1.3.26}): Physics-driven smooth inertial scrolling engine.
\item \textbf{React Hot Toast} (\texttt{\^2.4.1}): Non-blocking, accessible toast alerts customized with Neo-Bauhaus borders.
\item \textbf{React Hook Form} (\texttt{\^7.49.2}): High-performance form state management with minimal re-renders.
\end{itemize}

\subsection{Backend Layer}

\begin{itemize}
\item \textbf{Node.js} (\texttt{>=18.0.0}): Scalable JavaScript runtime environment running on V8.
\item \textbf{Express.js} (\texttt{\^4.18.2}): Minimalist web application framework for routing, middleware pipelines, and API endpoints.
\item \textbf{Mongoose} (\texttt{\^8.0.3}): Object Data Modeling (ODM) layer managing schemas, compound indexes, and hooks.
\item \textbf{Passport.js} (\texttt{\^0.7.0}): Authentication middleware orchestrating OAuth 2.0 social login.
\item \textbf{passport-google-oauth20} (\texttt{\^2.0.0}): Strategy for authenticating with Google via OAuth 2.0.
\item \textbf{jsonwebtoken (JWT)} (\texttt{\^9.0.2}): Signed bearer access tokens (short-lived) and refresh tokens (long-lived).
\item \textbf{bcryptjs} (\texttt{\^2.4.3}): Salted 10-round one-way password hashing.
\item \textbf{node-cron} (\texttt{\^4.6.0}): Background task runner executing hourly reminder schedules.
\item \textbf{@getbrevo/brevo} (\texttt{\^6.0.3}): Direct REST API client for transactional HTML emails and iCal attachments.
\item \textbf{cloudinary} (\texttt{\^2.8.0}): Cloud-based media storage and image optimization CDN for business logos and banners.
\item \textbf{multer} (\texttt{\^1.4.5-lts.1}): In-memory multipart/form-data handler for file uploads.
\item \textbf{cookie-parser} (\texttt{\^1.4.6}): HTTP cookie serialization and parsing for secure refresh token handling.
\item \textbf{cors} (\texttt{\^2.8.5}): Cross-Origin Resource Sharing control with dynamic origin matching.
\item \textbf{dotenv} (\texttt{\^16.3.1}): Environment variable injector.
\end{itemize}
